急救

人不在电脑前时，用手机把卡住的 iTerm2 救回来

管什么用：Mac 内存一紧，系统会把管权限的 tccd 关掉，之后 iTerm2 里读写外置盘全报 Operation not permitted，新开窗口也没用，要重启 iTerm2 才好。 急救在手机上告诉你 iTerm2 现在还能不能读外置盘，一键重启 iTerm2：窗格里的程序（Claude 等）不会断，窗格摆回原来的窗口、标签页和分屏位置。

两边都要装：急救装在手机上，急救助手装在 Mac 上。手机和 Mac 连在同一个 WireGuard 网里。

装的时候人要在电脑前

控制 iTerm2打开后会弹「RescueMac 想要控制 iTerm」，点允许。读窗格、重启后把窗格摆回原位都要它。 这个框只有坐在电脑前才点得到（远程点不了），所以装好当场就点掉。没弹或者当时没点，之后在菜单栏急救图标里点允许控制 iTerm2。
iTerm2 的 Python 接口iTerm2 → 设置 → General → Magic → 勾上 Enable Python API（用过 Pane 的已经勾了）。
开机自动打开不用设，助手自己会登记。

没给“控制 iTerm2”时也能重启 iTerm2，只是窗格不会摆回原位，手机上会提示还缺这个授权。

在手机上连它

  1. 手机打开 WireGuard 和急救，填这台 Mac 的 WireGuard 地址（菜单栏急救图标里能看到）
  2. Mac 上会弹「XX 想连接急救助手」，点允许；人不在电脑前就在手机上输配对口令（菜单里能看、能改）

以后不用再来这一页：菜单里点「检查更新」，有新版会自动替换。
