Pane 助手

版本 1.0+202609241243 · 需要 macOS 15 以上 · Apple Silicon

装在要被遥控的 Mac 上。它常驻在菜单栏（分屏图标），让 iPhone 上的 Pane 通过 WireGuard 看到、操作这台 Mac 的 iTerm2 窗格和 Chrome 等窗口。

iPhone 端从 Pane 安装页 装。

1先准备好

WireGuard这台 Mac 要连在同一个 WireGuard 网里（比如 10.0.1.x），手机才能连到它。
iTerm2 的 Python 接口iTerm2 → 设置 → General → Magic → 勾上 Enable Python API。 已经勾着但还连不上时，取消再重新勾一次（iTerm2 只在勾选或启动时才打开接口）。
Python不用单独装：助手会自动用 iTerm2 自带的，或者用这台 Mac 上的 Python 3 建一个（第一次要联网，几秒到一两分钟）。

不用 iTerm2 也能装，只是手机上就只能看普通窗口，看不到终端窗格。

2下载安装

下载 PaneMac.dmg
  1. 双击挂载 dmg
  2. 把 PaneMac 拖到旁边的「应用程序」
  3. 从「应用程序」里打开（别在 dmg 里直接双击运行）

3第一次打开会被拦，这样放行

这个包没有经过 Apple 公证，下载后 macOS 会拦住。在终端跑一行就好：

xattr -dr com.apple.quarantine /Applications/PaneMac.app && open /Applications/PaneMac.app

或者：先双击打开一次，被拦后去「系统设置 → 隐私与安全性」，往下拉，点「仍要打开」。

4给它权限

点菜单栏的分屏图标，按提示打开：

控制 iTerm2第一次会弹「PaneMac 想要控制 iTerm」，点允许。不点的话看不到终端。
屏幕录制看 Chrome 等普通窗口要用。
辅助功能在手机上点、滑普通窗口要用。
登录时打开菜单里勾上，开机自动运行。

5在手机上连它

  1. 手机打开 WireGuard 和 Pane
  2. 点首页顶上那一行（连的是哪台 Mac）→ 添加或管理 Mac
  3. 在「WireGuard 里的设备」里找到这台（显示「有 Pane 助手」），点它
  4. 这台 Mac 上会弹「XX 的 iPhone 想连接这台 Mac」，点允许

以后在首页顶上那一行就能在几台 Mac 之间切换。每台 Mac 的首页窗口分开记。

6推送（可选）

Claude Code 做完、等你回复时推送到手机，需要一个 APNs 密钥（.p8）。 在菜单栏图标里「推送：选择密钥文件…」装上。每台 Mac 各装一次。

7以后怎么更新

不用再来这个页面。助手每次打开和每 6 小时会自己查一次新版，有新版时菜单栏图标的菜单里会出现 更新到新版，点一下自动下载、替换、重新打开，给过的权限都还在。 也可以随时点菜单里的 检查更新。
