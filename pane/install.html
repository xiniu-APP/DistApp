Pane

在手机上看、操作电脑上的终端和窗口

强烈建议配合豆包输入法使用：手机上装好豆包输入法，按住说话就能输入。给 AI 下指令、改文字、敲命令，一切都能用嘴说，不用一个字一个字打。

两边都要装：客户端装在手机上，服务端（Pane 助手）装在要被遥控的电脑上。手机和电脑连在同一个 WireGuard 网里。

客户端
装在手机上
iPhone
版本 1.0 (202609300939) · 大小 1.0 MB · 需要 iOS 18 以上
安装到 iPhone
  1. 用 iPhone 上的 Safari 打开这一页（微信里打开装不了）
  2. 点上面的按钮，在弹窗里点「安装」，回桌面等图标装好

这是 Ad Hoc 包，只能装在开发者后台登记过的 iPhone 上；换了新手机要先登记设备再重新打包。 描述文件一年过期，过期后重新打包安装即可。以后 App 里会提示更新，覆盖安装，配对和首页窗口都还在。

安卓
版本 1.0 (202609300938) · 大小 4.3 MB · 需要 Android 9 以上
下载 Pane.apk
  1. 用手机浏览器打开这一页，点上面的按钮下载
  2. 打开下载好的文件安装；第一次会提示「允许安装未知来源的应用」，去设置里允许一下

手机要开着 WireGuard。安卓版没有推送（Mac 助手只会发 iPhone 的推送），其他和 iPhone 一样。 以后 App 里会提示更新，下载新的安装包覆盖安装，配对和首页窗口都还在。

服务端
装在要被遥控的电脑上（Pane 助手）

先看这里：每种电脑用哪种终端、能用什么

手机上只能看到下表“终端”这一列里开着的窗格，别的终端看不到。“测过的”是我们实际用过的环境，别的版本大概率也行，但没测过。

电脑终端要先装好Codex
MaciTerm2
测过：iTerm2
系统自带的“终端”、Warp 等不支持		 iTerm2，打开它的 Python 接口不用设置
WindowsWSL 里的 tmux
测过：WSL + Ubuntu 24.04 + tmux 3.4		 WSL，WSL 里装 tmux要设置（见下）
Linuxtmux
测过：Ubuntu 24.04 + tmux 3.4		 tmux要设置（见下）

Claude Code

不用设置，手机上往上拖就能翻它的历史。

测过：Mac 的 iTerm2 Windows、Linux 的 tmux 里按道理一样，还没用真的 Claude 测过。

Codex（在 tmux 里用时要设置）

Codex 在 tmux 里默认用“全屏”模式，对话不留在终端历史里，手机上往上翻不了。在那台电脑上（Windows 是在 WSL 里）的 ~/.codex/config.toml 加上这两行：

[tui]
alternate_screen = "never"

改完退出 Codex 再打开，用 codex resume --last 能接着原来的对话。Mac 的 iTerm2 里不用改。

普通窗口（浏览器等）

Mac、Windows 上的普通窗口手机上能看、能点；Linux 没有（服务器没有桌面）。

开关（手机上打开、关闭电脑上的程序）

Mac、Windows 有，Linux 没有。在手机的开关页里自己挑几个程序：Mac 上是「应用程序」里的 App（一开始先放好了 iTerm2）； Windows 上是开始菜单「所有应用」里的程序，应用商店装的（记事本、终端）也行。电脑上 iTerm2 没开时，手机上先在这里把它打开。

配对口令：装好先改

新手机第一次连时，电脑上会弹「允许」；人不在电脑前，就在手机上输配对口令放行。三种助手默认都是 123456，装好先改掉： Mac 在菜单栏图标里「配对口令…」，Windows 在托盘菜单里「配对口令…」，Linux 在管理页里。

Mac 助手
版本 1.0 (202609300539) · 大小 1.1 MB · 需要 macOS 15 以上 · Apple Silicon
下载 PaneMac.dmg
  1. 双击挂载 dmg，把 PaneMac 拖到旁边的「应用程序」
  2. 这个包没有经过 Apple 公证，第一次打开前在终端跑一行：
xattr -dr com.apple.quarantine /Applications/PaneMac.app && open /Applications/PaneMac.app

或者先双击打开一次，被拦后去「系统设置 → 隐私与安全性」点「仍要打开」。

先准备好

iTerm2 的 Python 接口终端要开在 iTerm2 里。iTerm2 → 设置 → General → Magic → 勾上 Enable Python API。 已经勾着但还连不上时，取消再重新勾一次。
Python不用单独装：助手会自动用 iTerm2 自带的，或者用这台 Mac 上的 Python 3 建一个（第一次要联网）。

给它权限

控制 iTerm2第一次会弹「PaneMac 想要控制 iTerm」，点允许。不点的话看不到终端。
屏幕录制看 Chrome 等普通窗口要用。
辅助功能在手机上点、滑普通窗口要用。
开机自动打开不用设，助手自己会登记。要是系统让你批准，菜单里会提示去「系统设置 → 通用 → 登录项」打开。

在手机上连它

  1. 点首页顶上那一行 → 添加或管理电脑，在「WireGuard 里的 Pane 助手」里点这台。 扫的是首页顶上选的网络；没扫到就在「手动填地址」里填这台 Mac 的 WireGuard 地址
  2. Mac 上会弹「XX 想连接这台 Mac」，点允许；人不在 Mac 前就在手机上输配对口令

推送（可选）：Claude Code 做完、等你回复时推到手机，要在菜单栏图标里「推送：选择密钥文件…」装一个 APNs 密钥（.p8），每台 Mac 各装一次。
以后不用再来这一页：助手自己查新版，菜单里点更新到新版就自动替换，权限都还在。

Windows 助手
版本 1.0 (202609300858) · 大小 68.3 MB · Windows 10 / 11（64 位）
下载 PaneWin.exe
  1. 双击运行。exe 没有签名，第一次可能提示「Windows 已保护你的电脑」，点更多信息 → 仍要运行
  2. 它会自己装好，常驻在右下角托盘（分屏图标），以后开机自动运行。第一次会弹一次管理员确认，是给防火墙放行手机的连接，点“是”
  3. 装 WSL：管理员 PowerShell 里运行 wsl --install，按提示重启。助手会自己在 WSL 里装好终端部分， 先装 exe 还是先装 WSL 都行（WSL 装好后半分钟内自己接上）
  4. 在 WSL 里装 tmux：sudo apt install tmux
  5. 以后终端都开在 WSL 的 tmux 里：打开 WSL，运行 tmux new -A -s main。 也可以在手机「电脑上正在运行」里点新开一个窗口，桌面上会开一个接着 tmux 的终端

在手机上连它

  1. 点首页顶上那一行 → 添加或管理电脑，在「WireGuard 里的 Pane 助手」里点这台；没扫到就手动填它的 WireGuard 地址
  2. 托盘会弹「允许」，点允许；人不在电脑前就在手机上输配对口令

用 Codex 的话，先照上面“先看这里”改一下它的设置。有新版时托盘菜单里会出现“更新到新版”。

Linux 助手
版本 1.0 (202609300857) · 大小 7.7 MB · 服务器也行 · x86_64 / arm64
下载 pane-helper（x86_64）

ARM 的机器下载 arm64 版。

  1. 先装 tmux（Ubuntu / Debian：sudo apt install tmux），终端开在 tmux 里：tmux new -A -s main
  2. 传到那台机器上，运行：chmod +x pane-helper-linux-* && ./pane-helper-linux-* install
  3. 装好后浏览器打开 http://那台机器的地址:7789，用配对口令（默认 123456）登录管理页：改口令、看连着的手机、装推送密钥、一键更新

在手机上连它

  1. 点首页顶上那一行 → 添加或管理电脑，在「WireGuard 里的 Pane 助手」里点这台；没扫到就手动填它的 WireGuard 地址
  2. 服务器上没法弹「允许」，在手机上输配对口令

装在有公网 IP 的服务器上要注意：7788（手机连）和 7789（管理页）在所有网卡上监听，公网也能访问，管理页还是明文 http。 在防火墙里只放行 WireGuard 网段，并先改掉默认口令。

用 Codex 的话，先照上面“先看这里”改一下它的设置。 有 systemd 的话自动装成开机服务。只能看 tmux 里的窗格，没有普通窗口画面。
