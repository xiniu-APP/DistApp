Pane

在手机上看、操作电脑上的终端和窗口

两边都要装：客户端装在手机上，服务端（Pane 助手）装在要被遥控的电脑上。手机和电脑连在同一个 WireGuard 网里。

客户端
装在手机上
iPhone
版本 1.0 (202609251450) · 需要 iOS 18 以上
安装到 iPhone
  1. 用 iPhone 上的 Safari 打开这一页（微信里打开装不了）
  2. 点上面的按钮，在弹窗里点「安装」，回桌面等图标装好

这是 Ad Hoc 包，只能装在开发者后台登记过的 iPhone 上；换了新手机要先登记设备再重新打包。 描述文件一年过期，过期后重新打包安装即可。以后 App 里会提示更新，覆盖安装，配对和首页窗口都还在。

安卓
版本 1.0 (202609251449) · 需要 Android 9 以上
下载 Pane.apk
  1. 用手机浏览器打开这一页，点上面的按钮下载
  2. 打开下载好的文件安装；第一次会提示「允许安装未知来源的应用」，去设置里允许一下

手机要开着 WireGuard。安卓版没有推送（Mac 助手只会发 iPhone 的推送），其他和 iPhone 一样。 以后 App 里会提示更新，下载新的安装包覆盖安装，配对和首页窗口都还在。

服务端
装在要被遥控的电脑上（Pane 助手）
Mac 助手
版本 1.0 (202609251434) · 需要 macOS 15 以上 · Apple Silicon
下载 PaneMac.dmg
  1. 双击挂载 dmg，把 PaneMac 拖到旁边的「应用程序」
  2. 这个包没有经过 Apple 公证，第一次打开前在终端跑一行：
xattr -dr com.apple.quarantine /Applications/PaneMac.app && open /Applications/PaneMac.app

或者先双击打开一次，被拦后去「系统设置 → 隐私与安全性」点「仍要打开」。

先准备好

WireGuard这台 Mac 要连在同一个 WireGuard 网里（比如 10.0.1.x），手机才能连到它。
iTerm2 的 Python 接口iTerm2 → 设置 → General → Magic → 勾上 Enable Python API。 已经勾着但还连不上时，取消再重新勾一次。
Python不用单独装：助手会自动用 iTerm2 自带的，或者用这台 Mac 上的 Python 3 建一个（第一次要联网）。

给它权限

控制 iTerm2第一次会弹「PaneMac 想要控制 iTerm」，点允许。不点的话看不到终端。
屏幕录制看 Chrome 等普通窗口要用。
辅助功能在手机上点、滑普通窗口要用。
开机自动打开不用设，助手自己会登记。要是系统让你批准，菜单里会提示去「系统设置 → 通用 → 登录项」打开。

在手机上连它

  1. 手机打开 WireGuard 和 Pane
  2. 点首页顶上那一行 → 添加或管理电脑，在「WireGuard 里的设备」里点这台
  3. Mac 上会弹「XX 的 iPhone 想连接这台 Mac」，点允许

推送（可选）：Claude Code 做完、等你回复时推到手机，要在菜单栏图标里「推送：选择密钥文件…」装一个 APNs 密钥（.p8），每台 Mac 各装一次。
以后不用再来这一页：助手自己查新版，菜单里点更新到新版就自动替换，权限都还在。

Windows 助手
版本 1.0 (202609251335) · Windows 10 / 11（64 位）
下载 PaneWin.exe
  1. 双击运行。它会自己装好，常驻在右下角托盘（分屏图标），以后开机自动运行
  2. 第一次会弹一次管理员确认，是给防火墙放行手机的连接，点“是”

Windows 的普通窗口（浏览器等）手机上能看、能点。终端要用 WSL 里的 tmux：先装 WSL（管理员 PowerShell 里 wsl --install）， 助手会自己在 WSL 里装好终端部分；终端开在 tmux 里（tmux new -A -s main）。 新手机连上来时托盘会弹“允许”，人不在电脑前就在手机上输配对口令（默认 123456，托盘菜单里改）。有新版时托盘菜单里会出现“更新到新版”。

Linux 助手
版本 1.0 (202609251335) · 服务器也行 · x86_64 / arm64
下载 pane-helper（x86_64）

ARM 的机器下载 arm64 版。

  1. 先装 tmux（Ubuntu / Debian：sudo apt install tmux），终端开在 tmux 里：tmux new -A -s main
  2. 传到那台机器上，运行：chmod +x pane-helper-linux-* && ./pane-helper-linux-* install
  3. 装好后浏览器打开 http://那台机器的地址:7789，用配对口令（默认 123456）登录管理页：改口令、看连着的手机、装推送密钥、一键更新

有 systemd 的话自动装成开机服务。服务器上没法弹“允许”，新手机第一次连时在手机上输配对口令。只能看 tmux 里的窗格，没有普通窗口画面。
