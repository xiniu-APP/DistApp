MacGuard

版本 __VERSION__ · 需要 macOS 14 以上 · Apple Silicon
装之前先看这条：它离不开 Clash Verge

MacGuard 不抓包、不装系统扩展，它是读本机 mihomo 的连接数据来知道你在访问什么。

所以这台机器上必须有 Clash Verge 在跑，且开着 TUN。没有的话 MacGuard 装上也是空转，菜单栏图标会一直是警示态。

1确认前置条件

在终端里跑这行，四项都要通过：

ls /tmp/verge/verge-mihomo.sock && \
curl -s --unix-socket /tmp/verge/verge-mihomo.sock \
  http://localhost/configs | python3 -c "
import sys,json; d=json.load(sys.stdin); t=d.get('tun',{})
print('TUN 开启      :', t.get('enable'))
print('auto-route    :', t.get('auto-route'))
print('DNS 模式      :', d.get('dns',{}).get('enhanced-mode','?'))
print('mihomo 可访问 : True')"

期望看到 TUN 与 auto-route 都是 True。
如果提示找不到 socket，说明 Clash Verge 没运行，或者它的控制接口不是 unix socket （在 Clash Verge 设置里可以看到）。

用 sing-box 或别的内核也行，但要自己改 config.json 里的 mihomoSocketPath，接口得兼容 Clash API 的 /connections。

2下载安装

下载 MacGuard.dmg
  1. 双击挂载 dmg
  2. 把 MacGuard 拖到旁边的「应用程序」
  3. 从「应用程序」里打开（别在 dmg 里直接双击运行）

3首次打开会被拦，这样放行

__SIGNING_NOTE__

4打开之后做什么

它不在 Dock 里显示，只在菜单栏右上角有一个环形图标。

黑名单默认是空的，所以装好之后它什么都不会做。点菜单栏图标 → 设置 → 黑名单， 加上你想封的关键词。

关键词是对域名做子串匹配，大小写不敏感。填 bilibili 会命中 www.bilibili.com、m.bilibili.com、 api.live.bilibili.com 等等。

注意会误伤：填 tube 会同时命中 youtube.com 和 tubemogul.com。选具体一点的词。

建议先用短参数试一次

别一上来就 3 分钟。先把壁纸和宽限都改成 20 秒，加一个你现在就能访问的网站， 完整看一遍流程，确认打断效果符合预期，再调回去。

5它是怎么工作的

检测到黑名单域名有活跃流量右上角出现 10 秒倒计时
10 秒内你关掉了解除，什么都不发生
超时全屏壁纸 3 分钟，期间关不掉
壁纸结束恢复桌面 3 分钟，给你机会自己关
3 分钟后仍在访问再来一轮壁纸，直到流量消失

「有没有在用」看的是流量增量而不是连接是否存在—— 挂机的 keep-alive 长连接非常多（实测 67 条里 57 条零增长，最长挂了 2.8 天）， 按存在性判定的话循环永远退不出去。

所有记录存在本地 SQLite，菜单栏 → 查看统计可以在浏览器里看。 统计服务只监听 127.0.0.1，局域网内其他机器访问不到。

6它拦不住什么

这些是设计上就放弃的，不是 bug：

退出 Clash / 关掉 TUN数据源没了，只告警不惩罚
直接用 IP、改 hosts绕过 DNS，看不见
看本地已下载的文件零网络流量
在手机上看不是这台设备
kill -9 掉它约 10 秒后被 launchd 拉起

共同点是都需要你刻意去做一件事。这个工具要对抗的是无意识的滑向—— 手指自动敲出域名、回车、40 分钟过去了。真到了专门去改 hosts 的程度， 那已经不是习惯而是决定，软件拦不住决定，也不该拦。

7卸载

launchctl bootout gui/$(id -u)/com.aimoment.macguard
rm -f ~/Library/LaunchAgents/com.aimoment.macguard.plist
pkill -x MacGuard
rm -rf /Applications/MacGuard.app

# 连历史记录一起删（不想留统计数据的话）
rm -rf ~/Library/Application\ Support/MacGuard

菜单栏的「退出」要等 30 秒延迟确认。单独 pkill 会被 launchd 在约 10 秒后拉起，所以得先 bootout。

配置文件在 ~/Library/Application Support/MacGuard/config.json
可以直接编辑，改完自动热加载
