安装

  1. 下载（或点上面的按钮）
    curl -fsSLO https://github.com/xiniu-APP/DistApp/releases/download/aiguard-latest/aiguard.pyz
  2. 装到 Claude Code 和 Codex（没装的那个会跳过）
    python3 aiguard.pyz install
  3. 用 Codex 的话：打开 Codex，输入 /hooks，信任 aiguard 这一条（只要一次）。Claude Code 装上马上生效。

它管什么

直接拦 灾难级的：删根目录、系统目录、整个家目录或它下面的一级文件夹、整块盘、当前项目目录；路径里的变量为空时会落到这些地方的；抹盘、格式化、删 Time Machine 备份；强推 main。
弹窗确认 拿不准的：删项目和临时目录以外的东西、远程电脑上的删除、git reset --hard、git clean -f、强推别的分支。Claude Code 在终端里问；Codex 在 Mac 上弹系统对话框，2 分钟没人点就拦下。
放行 别的所有命令，什么都不输出。

本机的、ssh 到别的电脑上的、bash -c、docker exec、adb shell 里的命令都会拆开看（现成的防护工具多半看不到 ssh 里面）。

不影响 AI

  • 放行时什么都不输出，AI 的上下文里不多任何东西；只有拦下、确认的那一次，AI 收到一句原因。
  • 只看要执行的命令，读写文件、搜索都不经过它；每条命令多花 20 来毫秒。
  • 它自己出错一律放行，不会卡住 AI。

其他

看一条命令会怎样：

python3 aiguard.pyz check 'rm -rf ~/Documents'

更新：下载新的，再 install 一次。卸载：

python3 aiguard.pyz uninstall

要求：/usr/bin/python3（Mac 装了 Xcode 命令行工具就有）。拦下和确认记在 ~/.aiguard/log.jsonl。改设置前会备份成 *.bak-aiguard-时间。Windows 暂不支持。
