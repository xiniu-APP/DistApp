安装

  1. 下载（或点上面的按钮）
    curl -fsSLO https://github.com/xiniu-APP/DistApp/releases/download/aiguard-latest/aiguard.pyz
  2. 装到 Claude Code 和 Codex（没装的那个会跳过）
    python3 aiguard.pyz install
  3. Claude Code 装上马上生效；Codex 还要信任一次，见下面“在 Codex 里怎么用”。

在 Claude Code 里怎么用

  1. 装好就生效，不用重启，正在开着的会话也算。平时什么变化都没有。
  2. 灾难级的命令直接拦下，不会执行。AI 会收到一句“AI 防护拦下了这条命令：原因”，一般会自己换成安全的写法。 确实要做的话，你自己在 Claude Code 里输入 ! 加这条命令执行（! 开头的是你直接跑的，不经过防护）。
  3. 拿不准的命令：终端底部出现 Claude Code 自己的确认，写着“AI 防护：原因。确认要执行吗？”，选“是”才执行。 人在外面，用手机看着这个终端（比如 Pane）也能选。
  4. 试一下：让 Claude 执行下面这条（根目录下不存在的文件夹，就算没拦住也删不了任何东西），应该被拦下：
    rm -rf /aiguard-test

在 Codex 里怎么用

  1. 先信任一次：装好后打开 Codex，它会提示 Hooks need review。选 1. Review hooks，回车， 看到 PreToolUse 这一条（Source 是 ~/.codex/hooks.json，Command 里有 aiguard.py --agent codex）， 按 t 信任。也可以直接选 2. Trust all and continue。以后在 Codex 里输入 /hooks 随时能看， PreToolUse 那一行 Active 是 1 就是在管着。只要一次，以后更新 AI 防护不用重新信任。
  2. 平时什么变化都没有。灾难级的命令直接拦下，AI 会收到原因。
  3. 拿不准的命令：Codex 的钩子还不支持在终端里问，所以先拦下，AI 会把这条命令原样告诉你、说明为什么要执行。 你同意的话，在 Codex 里输入 ! 加这条命令自己执行（! 开头的是你直接跑的，不经过防护，AI 也没法冒充）。
  4. 没信任的话钩子不跑，Codex 启动时会一直提示 Hooks need review。

它管什么

直接拦 灾难级的：删根目录、系统目录、整个家目录或它下面的一级文件夹、整块盘、当前项目目录；路径里的变量为空时会落到这些地方的；抹盘、格式化、删 Time Machine 备份；强推 main。
在终端里确认 拿不准的：删项目和临时目录以外的东西、远程电脑上的删除、git reset --hard、git clean -f、强推别的分支。只在终端里确认，不弹任何窗口：Claude Code 用它自己的“是否允许”；Codex 先拦下，AI 把命令告诉你，同意就在 Codex 里输入 !命令 自己执行。人在外面用手机看终端也能确认。
放行 别的所有命令，什么都不输出。

本机的、ssh 到别的电脑上的、bash -c、docker exec、adb shell 里的命令都会拆开看（现成的防护工具多半看不到 ssh 里面）。

不影响 AI

  • 放行时什么都不输出，AI 的上下文里不多任何东西；只有拦下、确认的那一次，AI 收到一句原因。
  • 只看要执行的命令，读写文件、搜索都不经过它；每条命令多花 20 来毫秒。
  • 它自己出错一律放行，不会卡住 AI。

其他

看一条命令会怎样：

python3 aiguard.pyz check 'rm -rf ~/Documents'

更新：下载新的，再 install 一次。卸载：

python3 aiguard.pyz uninstall

看拦过、问过哪些命令：

tail ~/.aiguard/log.jsonl

要求：/usr/bin/python3（Mac 装了 Xcode 命令行工具就有）。改设置前会备份成 *.bak-aiguard-时间。Windows 暂不支持。
