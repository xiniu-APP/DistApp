Curfew

家长随时一键锁 / 解锁孩子的手机，也能设宵禁时段到点自动锁

家长的手机和孩子的手机装的是同一个 App，第一次打开时选“我是家长”或“这是孩子的手机”。

公开透明：孩子手机上始终写着“受家长管理”，锁定页写明是家长锁的、几点解锁；不读聊天、照片、位置，只管能不能用手机。电话和紧急呼叫不受影响。

  1. 先装家长手机，用管理员给的家长连接码加入家庭
  2. 家长手机上点“加孩子手机”，生成孩子连接码（10 分钟有效）
  3. 再装孩子手机，按下面对应的步骤设置好，扫码或输入连接码

  1. 用 iPhone 上的 Safari 打开这一页（微信里打开装不了）

安卓版准备中
孩子手机怎么设置
装好后在孩子手机上选“这是孩子的手机”
孩子的 iPhone
  1. 孩子的 Apple ID 要在家长的家庭共享里（家长 iPhone：设置 → 家人）
  2. 在孩子手机上点「请家长批准」，家长在弹窗里输入自己的 Apple ID 和密码
  3. 扫家长手机上的二维码，或输入连接码，给这台手机起个名字
  4. 允许通知：家长临时锁 / 解锁靠推送送达

锁定时所有 App 和网页盖上“家长已锁定”的限制页。宵禁时段到点自动锁，不用联网、App 不用开着。批准后孩子删不掉这个 App。

孩子的安卓手机
  1. 打开 App 选“这是孩子的手机”，按引导开启设备管理器（只用来锁屏）
  2. 允许忽略电池优化，不然后台会被系统关掉
  3. 国产手机还要打开自启动 / 允许后台运行（App 里按手机品牌给了去哪儿设置）
  4. 允许通知：通知栏会一直显示“受家长管理”
  5. 扫家长手机上的二维码，或输入连接码，给这台手机起个名字

锁定时手机直接锁屏，解开后显示“家长已锁定，XX:XX 解锁”，并带紧急电话按钮。要卸载得先在系统设置里停用设备管理器，停用时家长那边会标红提示。
