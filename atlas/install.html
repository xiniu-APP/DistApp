Atlas

在平板上浏览几台电脑的文件

两边都要装：客户端装在平板上，服务端（Atlas 服务）装在要看文件的电脑上。平板和电脑连在同一个 WireGuard 网里。 平板只能看、不能改电脑上的文件。

客户端
装在平板上
iPad
版本 — · 大小 — · 需要 iPadOS 18 以上
安装到 iPad
  1. 用 iPad 上的 Safari 打开这一页（微信里打开装不了）
  2. 点上面的按钮，在弹窗里点「安装」，回主屏幕等图标装好

这是 Ad Hoc 包，只能装在开发者后台登记过的 iPad 上；换了新 iPad 要先登记设备再重新打包。 描述文件一年过期，过期后重新打包安装即可。覆盖安装后，加过的电脑和配对都还在。

安卓平板
版本 1.0 (202609280232) · 大小 3.9 MB · 需要 Android 9 以上
下载 Atlas.apk
  1. 用平板上的浏览器打开这一页，点上面的按钮下载
  2. 打开下载好的文件安装；第一次会提示「允许安装未知来源的应用」，去设置里允许一下

平板要开着 WireGuard。样子和 iPad 版一样，横过来是左右分栏。新版下载后覆盖安装，加过的电脑和配对都还在。

服务端
装在要看文件的电脑上（Atlas 服务）

先看这里：三种电脑怎么装、怎么放行

新平板第一次连一台电脑，要电脑那边放行一次：在电脑上点「允许」，或者在平板上输这台电脑的配对口令（装好时随机生成的 6 位数字）。

电脑怎么装在哪放行新平板配对口令在哪看、改
Macdmg 里的菜单栏 App，拖进「应用程序」 Mac 上弹窗，点「允许」菜单栏图标里
Windows一个 exe，运行 install 管理网页 http://这台电脑:7791装的时候会打出来；管理网页里改
Linux一个程序，运行 install 管理网页 http://这台电脑:7791装的时候会打出来；管理网页里改

管理网页用配对口令登录，能放行 / 拒绝等着的平板、忘掉用过的平板、改口令。口令输错 5 次锁 10 分钟（平板和网页一起算）。 平板连电脑的 7790 端口，管理网页是 7791。

Mac
版本 1.0 (202609280233) · 大小 0.9 MB · 需要 macOS 15 以上 · Apple Silicon · 菜单栏 App
下载 AtlasMac.dmg
  1. 双击挂载 dmg，把 AtlasMac 拖到旁边的「应用程序」
  2. 这个包没有经过 Apple 公证，第一次打开前在终端跑一行：
xattr -dr com.apple.quarantine /Applications/AtlasMac.app && open /Applications/AtlasMac.app

或者先双击打开一次，被拦后去「系统设置 → 隐私与安全性」点「仍要打开」。

给它权限

完全磁盘访问权限不给的话平板上看不了「桌面」「文稿」「下载」和外接盘。系统设置 → 隐私与安全性 → 完全磁盘访问权限，打开 AtlasMac（列表里没有就点 + 加上）。
新平板第一次连时 Mac 上弹窗，点允许；人不在 Mac 前就在平板上输配对口令（菜单栏图标里看、改）。
开机自动打开菜单栏图标里打开「开机自动打开」。
Windows
版本 1.0 (202609280231) · 大小 6.8 MB · Windows 10 / 11（64 位）
下载 atlas-server-windows-amd64.exe
  1. 在下载的文件夹里空白处按住 Shift 点右键 →「在终端中打开」（或 PowerShell），运行： 
    Unblock-File .\atlas-server-windows-amd64.exe; .\atlas-server-windows-amd64.exe install
  2. 它会把自己复制到 %LOCALAPPDATA%\Atlas\atlas-server.exe，登录后自动运行，并打出配对口令和管理网页地址。之后下载的那个文件可以删掉
  3. 要是弹出「Windows 已保护你的电脑」：点更多信息 → 仍要运行（程序没有签名，只是没见过它）
  4. 防火墙：用「以管理员身份运行」的终端跑 install，会顺手放行 7790、7791；不是管理员的话，第一次有平板连时 Windows 会问，点「允许」

看口令：& "$env:LOCALAPPDATA\Atlas\atlas-server.exe" passcode；改口令在管理网页里，或者在后面加上新口令。 卸掉：把 passcode 换成 uninstall（配置留着，重装后平板不用重新配对）。

Linux
版本 1.0 (202609280231) · 大小 6.6 MB · 服务器也行 · x86_64 / arm64
下载 atlas-server（x86_64）

ARM 的机器下载 arm64 版。

  1. 传到那台机器上，运行：chmod +x atlas-server-linux-* && ./atlas-server-linux-* install
  2. 它会装到 ~/.local/bin/atlas-server；有 systemd 就装成开机服务（没人登录也运行），并打出配对口令和管理网页地址
  3. 浏览器打开 http://那台机器的地址:7791，用配对口令登录，在这里放行新平板

装在有公网 IP 的服务器上要注意：7790（平板连）和 7791（管理网页）在所有网卡上监听，公网也能访问，管理网页还是明文 http。 在防火墙里只放行 WireGuard 网段，比如 sudo ufw allow from 10.0.1.0/24 to any port 7790:7791 proto tcp。

看口令：~/.local/bin/atlas-server passcode，后面加上新口令就是改。卸掉：atlas-server uninstall（配置留着）。

在平板上连一台电脑

  1. 打开 Atlas，点顶栏的 +
  2. 扫到的电脑点一下就加上；没扫到就在「手动填地址」里填这台电脑的 WireGuard 地址
  3. 电脑那边放行：Mac 上点弹窗里的「允许」，Windows、Linux 在管理网页里点「允许」；人不在电脑前就在平板上输配对口令

放行一次以后，这台平板再连就不用了。在管理网页里「忘掉」它，下次要重新放行。
