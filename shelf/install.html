Shelf

版本 1.0 (202609261145) · iPhone · Mac · Windows · Linux · 安卓

团队文件中转站：手机、Mac 上随手把图片和文件传到服务器上自己的空间，每次上传都有记录，点一下复制文件在服务器上的路径。

iPhone 和安卓可以在相册、文件或任何 App 里「分享 → Shelf」；Mac 上直接把文件拖进窗口或 ⌘V。

注册要邀请码，找管理员要。

iPhone
安装到 iPhone
  1. 用 iPhone 上的 Safari 打开这一页（微信里打开装不了）
  2. 点上面的按钮，在弹窗里点「安装」，回桌面等图标装好

需要 iOS 18 以上。这是 Ad Hoc 包，只能装在开发者后台登记过的 iPhone 上；装不上就把设备登记一下再重新打包。以后 App 里会提示更新。

Mac
下载 Shelf.dmg
  1. 双击挂载 dmg，把 Shelf 拖到旁边的「应用程序」
  2. 这个包没有经过 Apple 公证，第一次打开前在终端跑一行：
xattr -dr com.apple.quarantine /Applications/Shelf.app && open /Applications/Shelf.app

或者先双击打开一次，被拦后去「系统设置 → 隐私与安全性」点「仍要打开」。需要 macOS 15 以上。更新时重新下载覆盖即可。

Windows
下载 Shelf-windows-x64.zip
  1. 解压，把 Shelf.exe 放到一个固定的地方（比如「文档」里建个 Shelf 文件夹），双击打开
  2. 第一次打开 Windows 可能提示「Windows 已保护你的电脑」（这个程序没有微软签名）：点「更多信息」→「仍要运行」
  3. 要在资源管理器里右键「发送到 → Shelf」：在 Shelf 的设置里打开

需要 Windows 10 / 11（64 位）。关窗口会藏到右下角托盘，从托盘菜单「退出」才真的退出。命令行也能传：Shelf.exe upload 文件。更新时重新下载覆盖 Shelf.exe。

Linux
下载 Linux（x86_64） 下载 Linux（ARM64）
  1. 解压后进到文件夹里运行：
tar xzf shelf-linux-*.tar.gz && cd shelf-linux-* && ./install.sh

装在自己的目录下，不用 sudo：命令行 shelf、应用菜单里的 Shelf 窗口、文件管理器（Nautilus / Dolphin）右键「上传到 Shelf」。 窗口需要 Ubuntu 24.04 / Debian 13 / Fedora 40 以上（GTK 4.14、libadwaita 1.5）；没有桌面的服务器也能用命令行：shelf login、shelf upload 文件。卸载：./uninstall.sh。

安卓
下载 Shelf.apk
  1. 用手机浏览器打开这一页，点上面的按钮下载
  2. 打开下载好的文件安装；第一次会提示「允许安装未知来源的应用」，去设置里允许一下

需要 Android 8 以上。更新时重新下载安装，会直接覆盖，登录状态还在。
